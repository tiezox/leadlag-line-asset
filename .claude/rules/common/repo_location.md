# リポジトリは ~/projects/ に置いて作業する

この PC で作業するときは、リポジトリを WSL の `~/projects/<リポジトリ名>`(Windows からは `\\wsl.localhost\ubuntu\home\tiezo\projects\<リポジトリ名>`)に置いて作業する。デスクトップアプリが、フォルダを選ばずに始めたセッションのために作る仮のフォルダでは作業しない。そういうセッションで作業を頼まれたら、作業を始める前に、上の場所へセッションを移す。上の場所にまだリポジトリが無ければ、GitHub から clone する。

なぜ: 261114 に、仮のフォルダで作業していたところ、シェルが動かなくなり、元のフォルダにも戻せなくなった。仮のフォルダは、Windows の仕組みで実際には別の場所に置かれていて、アプリの道具から見つけられないことがある。また、セッションを消すと一緒に消える。
