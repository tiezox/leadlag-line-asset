# 作業の最初に最新を取り込む

リポジトリで作業を始める前に、`git pull --ff-only` を1回実行して GitHub の最新を取り込む。fast-forward できない(手元に未 push のコミットがある、作業中の変更とぶつかる等)ときは無理に進めず、状況をユーザーに報告する。この PC では、フック(`C:\Users\tiezo\.claude\hooks\pull_latest.py`)が、セッションの始めと、ユーザーがメッセージを送るたびに、自動で取り込む。フックが「決まりのファイルが変わった」と知らせたら、返事や作業より先にそのファイルを開いて読み直し、変わった内容をユーザーに伝えてから動く。

なぜ: 共通ルールのコピー(`.claude/rules/common/`)は GitHub 側の自動同期で更新されるので、取り込まないまま進むと古い決まりを読んだままになる。ほかのセッションや別の PC からの更新を取りこぼさないためでもある。
